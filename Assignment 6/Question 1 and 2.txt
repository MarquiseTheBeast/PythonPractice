[Question 2] Compare the while-loop and for-loop and identify which one is better in this context.
Response: I would say the for loop is the better choice because it will automatically read the next line in the text file after executing every iteration of the loop until the next line is empty, basically like repeating the block of inside code up to a max number of times. The while loop will repeatedly execute the code inside the block until the next line is read as empty, which also requires using the 'infile.readline()' in the loop to read the next text file line or else the while loop will be stuck in an infinite loop on the same line.
